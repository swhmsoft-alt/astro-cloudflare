# 自动化工具与调试防浪费规则

## 1. 工具调用限制
- **精确搜索**：在调用 `grep` 或 `search_grep` 时，关键词必须精准，禁止进行大范围、模糊的全局扫描。
- **文件读取**：严禁一次性读取超过 200 行的文件。如果文件过大，请先使用查看文件结构的工具，或分段读取关键函数。

## 2. 报错与调试循环控制 (关键)
- **一次过原则**：运行 `npm run build` 或检查报错时，如果修改一次后依然报错，**立即停止自动尝试**。
- **输出诊断报告**：停止后，用不超过 3 句话向用户汇报：1. 报错核心；2. 你认为的原因；3. 供用户选择的 2 种解决方案。得到允许后再行动。
- **禁止无限套娃**：严禁 Cline 自行连续尝试修改超过 2 次。
