# Do Not Create  未来 90 天不应创建的页面类型

> 结论基于本审计的真实数据（模块现实、重复风险、信息增益、决策链），不是预设立场。

## 明确 DO NOT CREATE

| # | 类型 | 证据 / 理由 |
|---|---|---|
| 1 | 再写一层Knowledge 文章（泛化 blog） | 已有 blog(3) 且营销/知识边界模糊；GEO 问题不是缺文章而是已写内容不可见 |
| 2 | 给 evidence/procurement/cases/applications 再加内容 | **先把已存在的 74 个文件渲染上线**；在接线前新增只会扩大雪藏浪费 |
| 3 | 泛化 What is Titanium 入门页 | 属于低信息增益、被大量同类竞争；DO NOT 覆盖信息增益最弱的意图 |
| 4 | 仅 FAQ 型页面 | 有 faqs 集合 + 各内容内嵌 faqs；重复堆 FAQ 是已识别的重复风险 |
| 5 | 同一意图的关键词变体页 | 见 content-overlap：comparisons/material-selection 已出现同实体重叠 |
| 6 | 空壳多语言页（除 de/es 外的 13 语言） | i18n-reality：16 语言路由但仅 en/de/es 有内容；继续生成空壳=重复内容+crawl 浪费 |
| 7 | 低词数薄页面 | cases 平均 37 词、applications 平均 111 词；不追数量，先加深已有薄页或合并 |
| 8 | 为新页面无脑加 Schema | schema 已覆盖 DefinedTerm/Product/CollectionPage/TechArticle/FAQ；应接线真实实体而非增加数量 |
| 9 | 供应商/报价营销落地页（在接线 procurement 之前） | 商业层断裂的根因是内容存在但无路由，不是缺营销页 |
| 10 | 泛化 guest post / PBN / 目录链接 | 见 offsite：应围绕实体权威，非普通 backlink |

## 核心原则

> 在接线 SCAFFOLD 内容与收敛语言之前，任何新增页面都优先级低于让已有资产可见。
