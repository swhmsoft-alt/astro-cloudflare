# Off-site Authority Map  站外实体权威，而非 backlink

> 目标：按实体权威而非链接数量规划站外。围绕本站已存在的强实体（grades/standards/evidence/comparisons/procurement）。

## 1. 区分四种站外信号（按价值排序）

| 类型 | 定义 | 价值 |
|---|---|---|
| Citation | 第三方引用本站具体资料（数据/表格/标准对照） | 最高 |
| Entity Association | 第三方把 titanium.blog 与 Titanium Engineering/Manufacturing 建立关联 | 高 |
| Entity Mention | 第三方提及 titanium.blog | 中 |
| Link | 第三方给 hyperlink | 中（承载上述） |
| Author/Expert Identity | 作者在外部建立专业身份 | 高（支撑 Citation） |

## 2. 可被引用的实体资产（对标Citation Magnet）

- Titanium Grade 属性数据库（materials + evidence 已含定量数据，但需接线可见）
- 材料对比矩阵（comparisons，含 decision framework）
- 加工参数/公差参考（evidence）
- 标准索引（standards + 认证 AS9100D/NADCAP）
- 采购/RFQ 清单（procurement）

## 3. 外部权威源（按 Tier）

Tier 1（优先）：工程/制造期刊、行业协会（ASM/IMET/TMS/ASTM）、技术社区（Reddit r/Machinists、Practical Machinist、Engineering Stack Exchange）、大学材料工程课程、标准相关出版物。
Tier 2：工业/供应商目录（ThomasNet 等）、工程论坛、LinkedIn 专业群。
Tier 3（不建议投入）：泛化 guest post、PBN、SEO 目录。

## 4. 落地建议

1. 先接线evidence/procurement/cases 使其可被引用（否则站外引用的 URL 是 404）。
2. LinkedIn 以Engineering reference: grade 5 vs grade 23形式持续发布数据资产（Author/Expert Identity + Entity Association）。
3. 以证据型内容换取专业引用（Citation），而非链接。

## 5. 限制

- 未做真实外链审计（需外部数据源）；本文件是基于站内实体资产的权威建设计划。
