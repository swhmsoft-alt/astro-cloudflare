## Overview

The Starrett T-1000 is an automatic tool presetter that enables offline tool measurement and compensation, reducing machine setup time by up to 90%.

## Key Specifications

- **Positioning Accuracy:** ±0.002 mm
- **Measuring Speed:** < 15 seconds per tool
- **Diameter Measurement Range:** Ø3–50 mm

## Typical Applications

- Quick changeover between production runs
- Quality control verification for critical machining operations
- Setup preparation for complex aerospace and medical components

## Engineering Notes

Offline tool presetting eliminates machine downtime for tool setup, enabling continuous production and improved Overall Equipment Effectiveness (OEE) by 15–20%.
