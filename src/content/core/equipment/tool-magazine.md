## Overview

The DMG MORI ATC-120 is a high-capacity automatic tool magazine supporting up to 120 tools, enabling long unattended machining cycles and complex multi-operation workflows.

## Key Specifications

- **Tool Capacity:** 60–120 tools (configurable)
- **Average Tool Change Time:** < 5 seconds
- **Tool Taper Compatibility:** Universal MT-BT standard

## Typical Applications

- Aerospace structural component families requiring multiple operations
- Multi-part family production with dedicated fixtures
- Turn-mill centers with complex tooling requirements

## Engineering Notes

Large tool magazines enable complete part completion in single setups, reducing handling time by 80% and enabling lights-out manufacturing for titanium parts.
