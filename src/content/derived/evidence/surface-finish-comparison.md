## Surface Finish by Process
| Process | Min Ra (µm) | Typical Ra (µm) |
|---------|-------------|-----------------|
| Rough Milling | 0.8 | 1.6–3.2 |
| Finish Milling | 0.2 | 0.4–0.8 |
| Precision Turning | 0.1 | 0.2–0.4 |
| Wire EDM (fine) | 0.1 | 0.2–0.4 |
| DMLS (as-built) | 3.0 | 6.0–10.0 |
| Polishing (mirror) | 0.01 | 0.05–0.20 |
| Electropolishing | 0.02 | 0.05–0.15 |
| Bead Blasting | 0.80 | 1.6–3.2 |
| Anodizing | 0.40 | 0.80–1.60 |

## Evidence Basis

Based on industry-standard surface-finish capability ranges and empirical testing. Ra values are typical capability bands per process, not certified guarantees — actual values depend on tooling, parameters, and part geometry.

## Engineering Interpretation (titanium.blog)

(titanium.blog) Each process has a characteristic Ra band: machining and EDM resolve 0.1-0.4 µm, additive (DMLS) is roughest as-built (3-10 µm) and requires post-processing, and polishing reaches mirror finishes below 0.1 µm. Select the finish process by functional need, not just the minimum achievable Ra.
